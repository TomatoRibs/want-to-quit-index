# 跑路指数测试

> 辞呈写了三遍，又删了三遍。
> 它不劝你走，也不劝你留，只把「有多想走」读成一个数。

一个 52 KB 的单文件 HTML，双击就开，断网也能玩，手机浏览器直接适配。

想跑路的理由，大多数人说不出。它散在几十个瞬间里：周三晚上十一点还在响的群，周日午后突然沉下去的那阵心情，刷招聘软件时手指停住的那一秒。这份测评把它们收成六组，一件一件勾出来，算成一个能看的读数。

**60 个选项 · 6 步 · 6 分钟 · 0 上传**

## 你会测出什么

| 档位 | 大致意思 |
|---|---|
| 低烧 | 想走的念头开始出现，还没成气候 |
| 持续低烧 | 不是突发念头，已经烧了一阵 |
| 明显超载 | 消耗已经盖过退路 |
| 红色预警 | 支持缺口明显大于压力 |

每档的完整判读文案以页面为准——比这张表锋利得多。

## 这 60 个选项长什么样

- 🫧 **开场 30 秒呼吸动画（可跳过）**——让你从「刚开完会」的状态里切出来再填
- 📊 **6 步 · 60 个选项**——起点（4 项）→ 频率 → 消耗（4 组 24 项）→ 信号（念头 · 身体 · 习惯，3 组 18 项）→ 准备（退路现状，单独成轴）→ 支持（4 项）
- 🧭 **压力 × 退路交叉落点**——读数交叉出你在哪一档，而不是一句空泛的「想走」
- 🧾 **单据式报告**——可复制文本摘要、复制结果链接、一键存图、打印成 PDF
- 🔒 **0 上传**——计算都在这台电脑里跑，没有服务器，也不联网

## 怎么用

1. 双击 `assets/want-to-quit-index.html`——无需联网、无需服务器、无需安装，手机浏览器可直接打开。
2. 呼吸动画后开始，逐组勾选，约 6 分钟。
3. 看报告，复制链接、存图或打印带走。

## 隐私

计算都在这台电脑里跑，没有服务器，也不联网，关掉页面就没了。只有你点「复制结果链接」，答案才会被塞进网址里——**转发链接等同于公开你的答案**，发给谁，你自己定。

## 可二创

题库就在 `assets/want-to-quit-index.html` 源码里，改几行文字就能换成你们团队的版本——「一个人自己能说出口的话」这个体例保留，内容随便换。改完配合 WorkBuddy 说一句话，就能再生成一份新的。

## 为什么做这个

说不清有多想走的时候，数字比决心先用得上。它不替你做决定，只把那团模糊的情绪拆成几条能看的数字——看清了，动不动都是你自己的事。
