# 跑路指数测试

一个关于「现在有多想走」的离职意愿自评工具。装好这个技能后，让 WorkBuddy 在当前工作区生成一份单文件 HTML 测评网页，双击即可离线打开使用。

## 它能做什么

- **30 秒静心仪式**：答题前先把情绪降下来，避免冲动填答污染分数（可跳过）。
- **6 组 60 题**：覆盖想走的频次、四项消耗（钱与长进 / 人与权 / 时间与边界 / 意义与身体）、三类信号（念头 / 身体 / 行为）、支持缺口、已有准备。
- **四维读数 + 双轴四象限**：消耗、信号、频次、支持缺口交叉出「压力 × 退路」落点，对应四档判读——低烧 / 持续低烧 / 明显超载 / 红色预警。
- **单据式报告**：带编号的存档单，可复制文本摘要、可分享 URL（答案只编码进网址）、可一键存图、可打印成 PDF。

## 特点

- 单文件 HTML，离线双击即用，零外部依赖。
- 全部计算在浏览器本地完成，不联网、不上传任何数据。
- 数据只存在本机，关掉页面即消失；除非主动复制分享链接，答案不会离开本机。

## 安装

方式一（已装进本地技能库）：直接在 WorkBuddy 中说「生成跑路指数测试网页」即可触发。

方式二（手动安装）：

```bash
bash scripts/install_local.sh /path/to/want-to-quit-index
```

## 使用

1. 让 WorkBuddy 把网页生成到当前工作区。
2. 双击打开，先走 30 秒静心仪式（可跳过）。
3. 答完 60 题，查看单据式报告。
4. 复制链接、存图或打印，带走你的结果。

## 重要说明

本工具是**基于工作心理学多个方向设计的自评工具**，不是标准化心理量表，未做信效度检验，不做临床诊断。它只把「现在有多想走」读成能看的条目；要不要动、什么时候动，是你自己的决定。
