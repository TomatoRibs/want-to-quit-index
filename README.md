# 我想跑路指数测试 · 使用说明

一份关于「现在有多想走」的离线自评网页。单文件、零依赖、不联网、不上传任何数据。

## 怎么用（最简单）
直接双击 `assets/quiz.html`，用任意浏览器打开即可。
- 不需要安装、不需要联网、不需要服务器。
- 关掉页面，刚才答的内容就清空了（答案只存在你这一次的浏览器里，不会上传）。

## 怎么放到自己网站上
把 `assets/quiz.html` 这一个文件上传到任意静态托管（GitHub Pages、Vercel、Netlify、对象存储、自己的服务器都行），访问它即可。
也可以改个名字，比如 `quit-index.html`，不影响功能。

## 文件结构
- `SKILL.md`：技能元信息，是给 WorkBuddy 看的，普通用户不用管。
- `assets/quiz.html`：就是这个测评网页本体，你需要的就是它。
- `LICENSE`：MIT 开源协议。

## 重要说明
这是一份「按工作心理学几个方向拆出来的自评工具」，**不是标准化心理量表**，没做信效度检验，也不做临床诊断。结果只帮你理清感受，不能替代专业判断。
